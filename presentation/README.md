# Presentación del proyecto IT-AI Classifier

Esta carpeta contiene la presentación ejecutiva del proyecto académico **IT-AI Classifier**, una solución basada en inteligencia artificial para apoyar la clasificación de incidentes de Soporte TI.

## Contenido

- `07_PRESENTACION_EJECUTIVA_IT_AI_Classifier.pptx`: presentación ejecutiva del proyecto.


## Temas de la presentación

- Problema de clasificación manual de incidentes.
- Preparación y análisis de datos sintéticos.
- Modelo de aprendizaje automático con TF-IDF y Regresión Logística.
- Resultados de evaluación y análisis de errores.
- Demostración del prototipo.
- Consideraciones éticas, limitaciones y viabilidad económica.
- Conclusiones y próximos pasos.

## Nota

El modelo se evaluó con datos sintéticos. Los resultados no garantizan el mismo desempeño en un entorno real. La implementación requeriría un piloto controlado y validación con tickets reales anonimizados.
