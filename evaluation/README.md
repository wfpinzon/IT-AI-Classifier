# Evaluación del proyecto IT-AI Classifier

Esta carpeta contiene los documentos y archivos utilizados para evaluar el prototipo de inteligencia artificial para la clasificación de incidentes de Soporte TI.

## Contenido

- `05_EVALUACION_RESULTADOS.docx`: métricas del modelo, análisis de errores y evaluación de resultados.
- `06_ANALISIS_ETICO_NEGOCIO_IT_AI_Classifier.docx`: análisis ético, riesgos, viabilidad económica y recomendaciones.
- `30_tickets_prueba_IT_AI_Classifier.csv`: muestra de 30 tickets preparada para revisión y validación humana.

## Resultados principales

El modelo obtuvo una exactitud del **98 %** sobre un conjunto de prueba de 200 tickets sintéticos. También se identificaron errores de clasificación entre las categorías Hardware e Impresoras.

**Nota:** la muestra de 30 tickets requiere validación humana por parte de un técnico. Los resultados obtenidos con datos sintéticos no garantizan el mismo rendimiento en un entorno real.

## Propósito

Documentar los resultados, las limitaciones y las oportunidades de mejora del prototipo antes de considerar una prueba piloto con tickets reales anonimizados.
